# PlayDota2Win 功能清单

本文描述 React 19 重写后的当前产品能力。历史设计过程保留在 `docs/plans/`，实际运行入口以
`src/router.tsx` 和 `worker/index.ts` 为准。

## 运行架构

- 浏览器端：React 19、React Router、Vite；`/` 与 `/download` 渲染下载页，`/admin`
  渲染管理后台，其余前端路径进入路由错误页。
- 边缘端：Cloudflare Worker 先处理 `/api/*`，其他请求交给静态资源绑定；未知前端路径由
  SPA fallback 返回入口文档。
- 数据：R2 保存规范化下载、分类与公告元数据，KV 保留迁移镜像和独立下载计数；R2 还保存
  托管文件、外链备份和失败计数对象。
- 样式：每个 React 组件使用独立 CSS Module，管理表单只共享一份全局表单 token；保留旧版
  色彩、字体、动画、断点、层级和移动端布局。

## 公开下载页

- 加载分类、公开公告、已启用下载项和总下载次数；包含加载、空数据、失败与重试状态。
- 按分类筛选下载项，显示平台、版本、文件大小、描述、分类和单项下载次数。
- 下载与配置指引双页签；下载完成后自动切到对应配置指引，并在当前页面会话中缓存已验证
  的指引。
- 下载密码校验；连续失败达到阈值后启用 Cloudflare Turnstile。Turnstile 加载、过期、错误和
  重试均有明确状态。
- 外部链接按文件名比较源站与 R2 的数字版本：R2 严格更新时自动优先，相同版本继续使用
  源站；用户也可显式选择已经就绪的 R2 备用下载。托管 R2/S3 文件由签名 URL 或受保护
  中转地址交付。
- 成功下载后同步更新页面总数和单项计数；打开链接使用独立上下文并阻断 opener。
- 配置指引支持安全 Markdown、复制文本、`mumble://` 和 HTTPS 操作。
- 密码、指引弹窗支持初始聚焦、焦点圈闭、Escape 关闭、焦点恢复与请求取消。

## 公告

- 公开页只展示可见公告，并按置顶与更新时间排序。
- 支持安全 Markdown：标题、粗体、链接、列表与换行；不直接注入未经处理的 HTML。
- 管理员可新增、编辑、删除、显示/隐藏和置顶/取消置顶公告。

## 管理后台

- HttpOnly 管理会话 Cookie 登录、登录状态探测与退出；管理请求和页面均禁止缓存。
- 顶部显示下载项数量，并提供下载、分类、公告、Mumble 状态四个页签。
- 下载项新增与编辑：平台、版本、分类、标题、描述、配置指引、文件名、大小、存储方式、
  链接/文件及 RustDesk 数据源标记。
- 存储方式：外部链接、Cloudflare R2 托管上传、自定义 S3 直传。R2 原始上传限制 90 MiB；
  S3 使用浏览器直传的预签名 PUT，不保存预签名地址。
- 下载列表支持启用/禁用、编辑、删除、批量操作、外链备份状态展示，以及把可备份的外链
  同步到 R2；外链镜像上限 200 MiB。
- 支持检查 Mumble 与官方 RustDesk 的 GitHub 最新稳定版，自动把目标 Windows 安装包写入
  R2，并同步版本、文件名和大小。RustDesk 配置接口使用同一版本选择规则；猴版安装器不作为
  独立更新目标。
- 分类支持新增、编辑、删除、排序、拖拽、上移/下移、emoji、颜色和描述；列表展示每个分类
  的下载项数量。
- Mumble 状态页展示代理健康、监控连接、频道、在线用户、最近文字消息，并支持刷新健康与
  重连监控。

## Mumble 文字与语音

- 非管理页面右下角提供可折叠浮窗；连接 WebSocket/WebRTC 代理，支持断线重连与状态提示。
- 昵称校验与关键字过滤、频道选择、在线用户、文字消息、未读计数和自动滚动。
- 语音发送/接收、麦克风权限、静音与音频播放解锁；交互客户端和只读后台监控使用同一套
  框架无关状态机。
- React 通过 external-store 接口订阅状态；组件卸载会释放 WebSocket、PeerConnection、媒体
  轨道、音频元素、定时器、动画帧和订阅。

## 安全与一致性

- 管理写请求校验同源 `Origin`/Fetch Metadata，拒绝跨站修改；会话 Cookie 使用 Secure、
  HttpOnly 和 SameSite。
- Worker 为 HTML、静态资源和 API 统一补充 CSP、禁止嗅探、Referrer Policy、Frame Policy、
  Permissions Policy，并为 HTTPS 响应启用 HSTS。
- 所有 JSON/上传入口限制请求体和字段长度；下载路径阻止目录穿越；外部地址只允许安全的
  绝对 HTTPS URL。
- 元数据写入使用 R2 ETag 条件更新检测并发冲突；生产环境缺失规范元数据或安全计数存储时
  失败关闭，不静默回退到过期数据。
- R2 下载支持 Range、条件请求、正确文件名和私有 no-store 响应。
